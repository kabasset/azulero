Welcome to Azulero!

Azulero is a toolbox for producing stunning color Euclid images.

It cleans and enhances MER data and combines the four Euclid photometric channels (I, Y, J, H) into an sRGB image. Input data are retrieved from public or private archives, and post-processing commands produce mesmerizing collages and flowing videos.

Azulero is compatible with Unix and Windows pipelines, which makes batch processing simple, including with parallelization. As an example, the collage below is the result of a single command line.
