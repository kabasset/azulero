Installation guide

Latest release

Azulero is deployed to PyPI. The simplest way to install it is with pip:

pip install azulero

If you already have an old version installed, use:

pip install --upgrade azulero

Development version

If you simply want to get the development version from time to time, use:

pip install git+https://github.com/kabasset/azulero

If instead, you want to modify the sources or update very often, better clone the repository locally:

git clone https://github.com/kabasset/azulero
cd azulero
pip install .

Azulero is packaged with uv. It is not needed to install the package to execute the scripts. For example, to download a cutout without installing, launch:

uv run azul retrieve NGC6505 -r 1m

Setup

Now that the package is available to you, you will need to configure it for accessing remote data providers. To this end, please follow the setup phases: Setup.
